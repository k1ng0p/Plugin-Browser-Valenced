
Plugin Browser

A standalone plugin browser for Valenced that lets you discover plugins from third-party repositories and add new repositories directly through Discord.

Installation

1. Open Revenge and navigate to Settings → General → Plugins → Add repository.

2. Paste the following repository URL:
   
   https://k1ng0p.github.io/Plugin-Browser-Valenced/

3. Add the repository and install Plugin Browser.

About

Plugin Browser is independently developed and maintained as a separate Plugin.

Valenced prioritizes its centralized repository. The unofficial repository channel is a temporary solution until the centralized repository becomes more established.

Since Plugin Browser is independently maintained and isn't controlled by the Valenced server team, it will not be distributed or supported through the Valenced server.

Features

- Browse plugins from third-party repositories.
- Discover available repositories.
- Add repositories directly through Discord.
- Explore plugins without manually entering repository URLs.

Support & Server Policy

Do not ask for Plugin Browser support, troubleshooting, or assistance in the Valenced server.

The Valenced server is focused on Valenced's centralized repository. Plugin Browser-related support requests are not permitted there.

Ignoring this policy may result in moderation action, including warnings or further disciplinary measures.

For Plugin Browser-related questions, issues, or support:

- Open an issue in this repository.
- Contact me directly through Discord.
