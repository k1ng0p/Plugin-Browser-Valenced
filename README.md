# Plugin Browser

**Discover, install and manage plugins for Valenced — all from inside Discord.**

Plugin Browser is a standalone plugin for **Valenced** that turns Discord into a full plugin manager. Browse third-party repositories, search across all of them at once, install in bulk, scan for malware, and keep everything up to date — without ever leaving the app.

---
## 📥 Installation

1. Open **Valenced** and go to **Settings → General → Plugins → Add repository**
2. Paste the repository URL:

```bash
https://k1ng0p.github.io/Plugin-Browser-Valenced/
```

3. Add the repository, then install **Plugin Browser**
4. Open the Community Plugins page — Plugin Browser now manages everything from there

## ✨ Features

### 🔍 Discovery & Search
- **Unified plugin browser** — browse plugins, themes and icons from all added repositories in one place
- **Global search** — search across every repository at once
- **Repository explorer** — browse individual repositories and inspect sources directly
- **Live counters** — real-time counts of repositories, plugins, themes, icons, installed plugins and available updates
- **Repository badges** — instantly see repo status: `OFFICIAL`, `TRUSTED`, `DEVELOPER`, `POPULAR`, `THEMES`, `UTILITY`, `PORTS`, `PLUGIN BROWSER AUTHOR` and more
- **Duplicate detection** — when the same plugin exists in multiple repositories, flags it (`LATEST OF 3 COPIES`, `NEWER ON <REPO>`) so you always install the right version
- **Copy detection** — know instantly when a repository is not yet added to Valenced

### 🛡️ Security
- **Built-in malware scanner** — statically scans plugin code for token grabbers, clipboard theft and other red flags
- **Three scan levels:**
  - **Per plugin** — scan any plugin before installing
  - **Per repository** — scan an entire repository from its info sheet
  - **Global scan** — deep-scan every plugin in every listed repository from settings
- **Scan before installing** — automatic warning when installing from unofficial repositories
- **Severity ratings** — findings labeled `HIGH` / `MEDIUM` / `CLEAN` with exact code locations you can tap to copy

> ⚠️ This is a basic static check. It can miss threats, so a clean scan does not prove a plugin is safe.

### ⚡ Bulk Management
- **Bulk install** — install multiple plugins from a repository in one tap
- **Bulk uninstall** — remove several plugins at once
- **Bulk enable / disable** — toggle every downloaded plugin at once (Plugin Browser and Valenced's own plugins stay on)
- **Pin versions** — stay on a specific plugin version and skip updates
- **One-tap updates** with haptic feedback (Android)

### 🔔 Notifications & Updates
- **Update notifications** — red count badge shows what changed in your repositories
- **Choose what counts:**
  - 🔔 Recently updated & new
  - ➕ New only
  - 🕒 Recently updated only
  - 🔕 Off
- Repositories can override notification behavior from their info sheet

### 🎨 Customization
- **Compact plugin cards** — hide author, contributors and version for a denser list
- **Haptic feedback** toggle
- Full plugin info sheets: settings, uninstall, pin version, channel selection and per-plugin scanning
